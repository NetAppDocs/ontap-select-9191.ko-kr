= ONTAP Select 클러스터 노드 크기 조정
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select 클러스터를 배포한 후 Deploy 관리 유틸리티를 사용하여 노드의 하이퍼바이저 인스턴스 유형을 업그레이드할 수 있습니다.


NOTE: Capacity Tiers 라이센스 모델 및 Capacity Pools 라이센스 모델을 사용할 때 클러스터 노드 크기 조정 작업을 수행할 수 있습니다.


NOTE: 대형 인스턴스 유형으로 크기를 조정하는 것은 ESXi에서만 지원됩니다.

.시작하기 전에
클러스터는 온라인 상태여야 합니다.

.이 작업 정보
이 작업에서는 Deploy 웹 사용자 인터페이스를 사용하는 방법에 대해 설명합니다. Deploy CLI를 사용하여 인스턴스 크기를 조정할 수도 있습니다. 어떤 인터페이스를 사용하든 크기 조정 작업에 필요한 시간은 여러 요인에 따라 크게 달라질 수 있으며 완료하는 데 상당한 시간이 소요될 수 있습니다. 노드 크기는 더 큰 크기로만 조정할 수 있습니다.

.단계
. 관리자 계정을 사용하여 Deploy 유틸리티 웹 사용자 인터페이스에 로그인하십시오.
. 페이지 상단의 *클러스터* 탭을 선택한 다음 목록에서 원하는 클러스터를 선택하십시오.
. 클러스터 세부 정보 페이지에서 페이지 오른쪽의 톱니바퀴 아이콘을 선택한 다음 *Instance Resize*를 선택합니다.
. *인스턴스 유형*을 선택하고 ONTAP 자격 증명을 제공한 다음 *수정*을 선택합니다.


.완료한 후
크기 조정 작업이 완료될 때까지 기다려야 합니다.
