= ONTAP Select 관리에 대해 알아보기
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs:

[role="lead"]
ONTAP Select 클러스터를 생성한 후에는 다양한 관리 작업을 수행하여 배포를 지원할 수 있습니다. 이때 몇 가지 일반적인 고려 사항을 숙지해야 합니다.

일반적으로 Deploy 웹 인터페이스를 사용하여 수행할 수 있는 절차는 세 가지 범주 중 하나에 속합니다.

.ONTAP Select 클러스터 배포
단일 노드 또는 다중 노드 클러스터를 배포할 수 있습니다. 자세한 내용은 link:task_deploy_cluster.html["ONTAP Select 클러스터 배포"]을(를) 참조하십시오.

.기존 ONTAP Select 클러스터를 사용하여 절차를 수행합니다.
관리 절차는 _Security_ 및 _Clusters_와 같은 다양한 범주로 구성되어 있습니다.

.Deploy 유틸리티에서 절차를 수행합니다
Deploy에는 관리자 암호 변경과 같은 몇 가지 특정 절차가 있습니다.



[[administer-ontap-select]]
== ONTAP Select 관리

ONTAP Select를 지원하는 과정에서 사용할 수 있는 다양한 관리 절차가 있습니다. 또한 Deploy 관리 유틸리티에 특화된 절차도 있습니다. 이러한 절차 중 가장 중요한 절차는 아래에 설명되어 있습니다. 일반적으로 모든 절차는 Deploy 웹 사용자 인터페이스를 사용합니다.


NOTE: link:https://docs.netapp.com/us-en/ontap-select/task_cli_signing_in.html["명령줄 인터페이스를 사용하십시오"]를 사용하여 ONTAP Select를 관리할 수도 있습니다.



[[perform-additional-ontap-configuration]]
== 추가 ONTAP 구성 수행

ONTAP Select 클러스터를 배포한 후에는 하드웨어 기반 ONTAP 시스템과 마찬가지로 클러스터를 구성하고 관리할 수 있습니다. 예를 들어 ONTAP System Manager 또는 ONTAP CLI를 사용하여 ONTAP Select 클러스터를 구성할 수 있습니다.

.NetApp 클라이언트 소프트웨어
다음과 같은 지원되는 NetApp 클라이언트 소프트웨어를 사용하여 ONTAP Select에 연결할 수 있습니다.

* ONTAP System Manager
* Active IQ Unified Manager
* OnCommand Insight
* OnCommand Workflow Automation
* SnapCenter
* VMware vSphere용 Virtual Storage Console


클라이언트 소프트웨어의 지원 버전을 확인하려면 link:https://mysupport.netapp.com/matrix/["상호운용성 매트릭스 도구"^]을(를) 참조하십시오. 클라이언트 소프트웨어가 ONTAP 9를 지원하는 경우 ONTAP Select에서도 동일한 버전이 지원됩니다.


NOTE: SnapCenter 및 관련 플러그인을 사용하려면 서버 기반 라이센스가 필요합니다. SnapCenter 플러그인의 스토리지 시스템 라이센스는 현재 ONTAP Select에서 지원되지 않습니다.

이 목록에 포함되지 않은 다른 NetApp 클라이언트 소프트웨어는 ONTAP Select에서 지원되지 않습니다.

.가능한 구성 옵션
클러스터를 구성할 때 사용할 수 있는 몇 가지 옵션이 있으며, 여기에는 다음이 포함됩니다.

* 네트워킹 구성 생성
* 애그리게이트 배치
* 데이터 스토리지 VM(SVM) 생성


.스토리지 용량이 있는 구매한 라이센스
ONTAP Select 클러스터 배포 시 스토리지 용량과 함께 라이센스 파일을 설치하지 않기로 결정한 경우, 구매한 라이센스로 실행 중인 클러스터에 대한 유예 기간이 만료되기 전에 라이센스 파일을 확보하여 설치해야 합니다.

.미러링된 애그리게이트
Deploy 관리 유틸리티는 사용 가능한 데이터 저장소 공간(예: Pool0 및 Pool1)에서 각 ONTAP Select 노드에 데이터 예비 디스크를 생성합니다. 다중 노드 클러스터에서 데이터의 고가용성을 구현하려면 이러한 예비 디스크를 사용하여 미러링된 애그리게이트를 생성해야 합니다.


NOTE: 고가용성 테이크오버는 데이터 애그리게이트가 미러링된 애그리게이트로 구성된 경우에만 지원됩니다.
