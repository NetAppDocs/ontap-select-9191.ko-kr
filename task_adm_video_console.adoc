= ONTAP Select 비디오 콘솔에 액세스합니다
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select가 실행 중인 하이퍼바이저 가상 머신의 비디오 콘솔에 액세스할 수 있습니다.

.이 작업 정보
문제를 해결하거나 NetApp 지원팀의 요청을 받은 경우 가상 머신 콘솔에 액세스해야 할 수 있습니다.

.단계
. vSphere 클라이언트에 접속하여 로그인하십시오.
. 계층 구조에서 적절한 위치로 이동하여 ONTAP Select 가상 머신을 찾으십시오.
. 가상 머신을 마우스 오른쪽 버튼으로 클릭하고 * 콘솔 열기 * 를 선택합니다.
