:allow-uri-read: 
:nofooter:

[role="lead"]
명령줄 인터페이스를 사용하여 필요에 따라 Deploy 가상 머신 관리자 계정의 암호를 변경하면 ONTAP Select 구축의 보안을 강화할 수 있습니다.

.단계
. 관리자 계정을 사용하여 배포 유틸리티 CLI에 로그인하십시오.
. 암호 변경:
`password modify`
. 사용자 환경에 맞게 모든 프롬프트에 응답하십시오.
