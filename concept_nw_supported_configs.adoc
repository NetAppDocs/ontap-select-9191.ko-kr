= 지원되는 ONTAP Select 네트워크 구성
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
최적의 성능과 복원력을 위해 최고의 하드웨어를 선택하고 네트워크를 구성하십시오.

서버 공급업체는 고객마다 요구 사항이 다르며 선택이 중요하다는 것을 이해합니다. 따라서 물리적 서버를 구매할 때 네트워크 연결 결정을 내릴 때 사용할 수 있는 다양한 옵션이 있습니다. 대부분의 범용 시스템은 속도 및 처리량의 다양한 순열과 함께 단일 포트 및 다중 포트 옵션을 제공하는 다양한 NIC 선택 사항과 함께 제공됩니다. 여기에는 VMware ESX를 사용한 25Gb/s 및 40Gb/s NIC 어댑터 지원이 포함됩니다.

ONTAP Select VM의 성능은 기본 하드웨어의 특성과 직접적으로 연관되어 있으므로 고속 NIC를 선택하여 VM의 처리량을 높이면 클러스터 성능이 향상되고 전반적인 사용자 경험이 개선됩니다. 고성능 네트워크 구성을 위해 10Gb NIC 4개 또는 고속 NIC 2개(25/40Gb/s)를 사용할 수 있습니다. 이 외에도 다양한 구성이 지원됩니다. 2노드 클러스터의 경우 1Gb 포트 4개 또는 10Gb 포트 1개를 지원합니다. 단일 노드 클러스터의 경우 1Gb 포트 2개를 지원합니다.

.네트워크 최소 및 권장 구성
클러스터 크기에 따라 지원되는 이더넷 구성이 여러 가지 있습니다.

[cols="30,35,35"]
|===
| 클러스터 크기 | 최소 요구 사항 | 권장 사항 


| 단일 노드 클러스터 | 2 x 1GbE | 2 x 10GbE 


| 2노드 클러스터 또는 MetroCluster SDS | 4 x 1GbE 또는 1 x 10GbE | 2 x 10GbE 


| 4개, 6개, 8개, 10개 또는 12개 노드 클러스터 | 2 x 10GbE | 4 x 10GbE 또는 2 x 25/40GbE 
|===

NOTE: 실행 중인 클러스터에서 단일 링크 토폴로지와 다중 링크 토폴로지 간의 변환은 각 토폴로지에 필요한 서로 다른 NIC 팀 구성 간의 변환이 필요할 수 있으므로 지원되지 않습니다.

.여러 개의 물리적 스위치를 사용한 네트워크 구성
충분한 하드웨어를 사용할 수 있는 경우, NetApp에서는 물리적 스위치 장애에 대한 추가적인 보호 기능을 제공하기 때문에 다음 그림에 표시된 멀티스위치 구성을 사용할 것을 권장합니다.
