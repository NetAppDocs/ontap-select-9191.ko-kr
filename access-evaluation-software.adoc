= ONTAP Select 평가 소프트웨어에 액세스하십시오
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select의 현재 고객이고 활성 사용 권한이 있거나 NetApp 파트너이며 새로운 Capacity Tiers 평가 라이센스를 다운로드하려는 경우 link:https://mysupport.netapp.com/site/downloads/evaluation/ontap-select["ONTAP Select 평가 소프트웨어"^]에 액세스할 수 있습니다.

위의 두 가지 경우에 해당하지 않고 평가를 위해 ONTAP Select를 사용해 보려는 경우 다음 단계에 따라 평가판 소프트웨어 다운로드 액세스를 요청할 수 있습니다.

.이 작업 정보
* 이 지침은 NetApp 영업 담당자, 파트너 및 NetApp과 협력하는 잠재 고객을 위한 것입니다.
* ONTAP Select Capacity Tiers 평가판 라이센스는 설치한 날로부터 90일로 제한됩니다.
+

NOTE: 평가판 라이선스는 연장할 수 없습니다. 90일이 지나면 라이선스가 더 이상 작동하지 않으며 관련 데이터에 액세스할 수 없습니다.

* 평가판 소프트웨어에는 ONTAP Select Deploy 관리 유틸리티를 다운로드하고 클러스터를 배포하는 데 필요한 모든 정보가 포함되어 있습니다.




[[step-1-register-for-an-account]]
== 1단계: 계정 등록

필요한 경우 NetApp 계정 등록을 완료하고 잠재 고객 액세스 권한을 요청하십시오.

.단계
. 새 계정을 만들거나 기존 계정에서 Sign out하세요.
+
[role="tabbed-block"]
====
.새 계정 만들기
--
회사 이메일을 사용하여 link:https://mysupport.netapp.com/site/user/registration["NetApp 지원 사이트"^]에서 계정을 등록하세요.


NOTE: gmail이나 yahoo와 같은 무료 이메일 계정은 허용되지 않습니다.

새로 생성한 계정으로 로그인되어 있지 않은지 확인하십시오.

--
.기존 계정
--
이미 계정이 있는 경우 link:https://mysupport.netapp.com/site/["NetApp 지원 사이트"^]로 이동하여 로그인되어 있지 않은지 확인하십시오.

--
====
. "prospect" 수준으로 액세스 레벨을 높이기 위해 비기술 지원 케이스를 생성합니다.
+
.. *CASES* 탭을 선택한 다음 *Create non-technical cases*를 선택하십시오
.. 피드백 카테고리로 *User Registration Issue*를 선택하세요.
.. *Create case*를 선택하십시오.
+
필수 정보를 모두 입력하시고, 댓글란에 "제 회사 이메일 주소는 <your-email-address>입니다. ONTAP Select 평가 소프트웨어를 다운로드할 수 있도록 잠재고객 접근 권한을 받고 싶습니다." 라고 적어주세요.

+
NetApp 담당자의 이름을 포함하십시오.

.. *Submit*을 선택합니다.






[[step-2-download-ontap-select-evaluation-software]]
== 2단계: ONTAP Select 평가 소프트웨어 다운로드

지원 요청이 검토 및 승인되면 NetApp 지원팀에서 제공하신 이메일 주소로 알림을 보내드립니다.

.단계
. https://mysupport.netapp.com/site/downloads/evaluation/ontap-select["ONTAP Select 평가 소프트웨어를 다운로드하십시오"^].
+
평가판 라이센스 파일은 zip 파일 내에 있습니다.

. 법적 요구 사항을 준수하려면 액세스 권한을 얻기 전에 link:https://mysupport.netapp.com/site/help["지원 사례 열기"^]해야 합니다. 이를 통해 NetApp은 필요한 운영 환경에 바로 사용할 수 있는 소프트웨어를 제공하는 동시에 올바른 관리 및 문서화를 유지할 수 있습니다.
+

NOTE: NetApp은 오픈 소스 또는 대체 버전이 아닌 "실제 운영 환경용" ONTAP Select 버전을 제공합니다. 지원은 프로덕션 라이선스로 업그레이드한 경우에만 제공됩니다.



.다음 단계
평가 소프트웨어 다운로드가 완료되면 지침에 따라 ONTAP Select Deploy 관리 유틸리티를 다운로드하고 클러스터를 배포하십시오.
