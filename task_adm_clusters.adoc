[[move-an-ontap-select-cluster-offline-and-online]]
== ONTAP Select 클러스터를 오프라인 및 온라인으로 이동

클러스터를 생성한 후에는 필요에 따라 오프라인 또는 온라인으로 전환할 수 있습니다.

.시작하기 전에
클러스터가 생성된 후 초기에는 온라인 상태입니다.

.단계
. 관리자 계정을 사용하여 Deploy 유틸리티 웹 사용자 인터페이스에 로그인하십시오.
. 페이지 상단의 *Clusters* 탭을 선택하고 목록에서 원하는 클러스터를 선택합니다.
. 클러스터 오른쪽에서 image:icon_kebab.gif["옵션"]을(를) 선택한 다음 *오프라인으로 전환*을 선택합니다.
+
오프라인 옵션을 사용할 수 없는 경우 클러스터는 이미 오프라인 상태입니다.

. 팝업 창에서 *예*를 선택하여 요청을 확인하십시오.
. 클러스터가 오프라인 상태인지 확인하려면 가끔 *새로 고침*을 선택하십시오.
. 클러스터를 다시 온라인 상태로 전환하려면 image:icon_kebab.gif["옵션"]을 선택한 다음 *온라인으로 전환*을 선택하십시오.
. 클러스터가 온라인 상태인지 확인하려면 가끔 *새로 고침*을 선택하십시오.




[[delete-an-ontap-select-cluster]]
== ONTAP Select 클러스터를 삭제합니다

ONTAP Select 클러스터가 더 이상 필요하지 않을 경우 삭제할 수 있습니다.

.시작하기 전에
클러스터는 오프라인 상태여야 합니다.

.단계
. 관리자 계정을 사용하여 Deploy 유틸리티 웹 사용자 인터페이스에 로그인하십시오.
. 페이지 상단의 *Clusters* 탭을 선택하고 목록에서 원하는 클러스터를 선택합니다.
. 클러스터 오른쪽의 image:icon_kebab.gif["옵션"]를 선택한 다음 * 삭제 * 를 선택합니다.
+
삭제 옵션을 사용할 수 없다면 클러스터는 오프라인 상태가 아닙니다.

. 클러스터가 목록에서 제거되었는지 확인하려면 가끔씩 *새로 고침*을 선택하십시오.




[[refresh-the-deploy-cluster-configuration]]
== Deploy 클러스터 구성 새로 고침

ONTAP Select 클러스터를 생성한 후에는 Deploy 유틸리티 외부에서 ONTAP 또는 하이퍼바이저 관리 도구를 사용하여 클러스터 또는 가상 머신 구성을 변경할 수 있습니다. 가상 머신의 구성은 마이그레이션 후에도 변경할 수 있습니다.

클러스터 또는 가상 머신에 이러한 변경 사항이 발생하면 Deploy 유틸리티 구성 데이터베이스가 자동으로 업데이트되지 않아 클러스터 상태와 동기화되지 않을 수 있습니다. 이러한 상황을 포함한 여러 상황에서 클러스터 새로 고침을 수행하여 클러스터의 현재 상태를 기반으로 Deploy 데이터베이스를 업데이트해야 합니다.

.시작하기 전에
필수 정보:: 클러스터의 최신 구성 정보를 가지고 있어야 합니다. 여기에는 다음 사항이 포함됩니다.
+
--
* ONTAP 관리자 자격 증명
* 클러스터 관리 IP 주소
* 클러스터의 노드 이름


--
안정적인 클러스터 상태:: 클러스터는 안정적인 상태여야 합니다. 클러스터가 생성 또는 삭제 중이거나 _create_failed_ 또는 _delete_failed_ 상태일 때는 클러스터를 새로 고칠 수 없습니다.
VM 마이그레이션 후:: ONTAP Select를 실행하는 가상 머신을 마이그레이션한 후에는 클러스터 새로 고침을 수행하기 전에 Deploy 유틸리티를 사용하여 새 호스트를 생성해야 합니다.


.이 작업 정보
웹 사용자 인터페이스를 사용하여 Deploy 구성 데이터베이스를 업데이트하기 위해 클러스터 새로 고침을 수행할 수 있습니다.


NOTE: Deploy UI를 사용하는 대신 Deploy CLI 셸에서 cluster refresh 명령을 사용하여 클러스터를 새로 고칠 수 있습니다.

클러스터 및 가상 머신 구성:: Deploy 데이터베이스가 동기화되지 않도록 만들 수 있는 구성 값 중 일부는 다음과 같습니다.
+
--
* 클러스터 및 노드 이름
* ONTAP 네트워크 구성
* ONTAP 버전(업그레이드 후)
* 가상 머신 이름
* 호스트 네트워크 이름
* 스토리지 풀 이름


--
클러스터 및 노드 상태:: ONTAP Select 클러스터 또는 노드가 제대로 작동하지 못하게 하는 상태에 있을 수 있습니다. 다음 조건을 수정하려면 클러스터 새로 고침 작업을 수행해야 합니다.
+
--
* _알 수 없는_ 상태의 노드 ONTAP Select 노드는 노드를 찾을 수 없는 경우를 포함하여 여러 가지 이유로 _알 수 없는_ 상태가 될 수 있습니다.
* 클러스터가 _성능 저하_ 상태인 경우 노드의 전원이 꺼져 있어도 Deploy 유틸리티에서는 온라인 상태로 표시될 수 있습니다. 이 경우 클러스터는 _성능 저하_ 상태입니다.


--


.단계
. 관리자 계정을 사용하여 Deploy 유틸리티 웹 사용자 인터페이스에 로그인하십시오.
. 페이지 왼쪽 상단의 *Clusters* 탭을 선택하고 목록에서 원하는 클러스터를 선택하십시오.
. 페이지 오른쪽에서 image:icon_kebab.gif["옵션"]를 선택한 다음 *클러스터 새로 고침*을 선택합니다.
. *클러스터 자격 증명* 항목에 클러스터의 ONTAP 관리자 암호를 입력하십시오.
. *새로 고침*을 선택합니다.


.완료한 후
작업이 성공적으로 완료되면 _Last Refresh_ 필드가 업데이트됩니다. 클러스터 새로 고침 작업이 완료된 후에는 Deploy 구성 데이터를 백업해야 합니다.
