= ONTAP Select 클러스터의 90일 평가판 인스턴스 배포
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
VMware ESXi에서 OVF 템플릿을 사용하여 단일 노드부터 최대 99개 노드까지 다양한 크기의 ONTAP Select 클러스터 90일 평가판 인스턴스를 배포할 수 있습니다. 기존 고객 또는 신규 고객 모두 평가판 라이선스를 다운로드할 수 있습니다. 예를 들어, 기존 고객이 라이선스를 구매하기 전에 새로운 구성을 시험해 보려는 경우입니다.

.이 작업 정보
* NetApp에서 일련 번호 또는 스토리지 용량 라이센스를 받을 필요가 없습니다.
* 구매한 라이선스와 동일한 용량의 스토리지를 사용자 데이터에 할당할 수 있습니다.
* vCenter 계정만 사용하여 OVF 템플릿을 배포할 수 있습니다. 현재 ESXi 호스트에 직접 설치하는 것은 지원되지 않습니다.
* vSphere 독립 실행형 클라이언트 또는 vSphere 웹 클라이언트(ESXi 8.0 이상에서는 유일한 옵션)를 사용하여 OVF 템플릿(ova 파일에 포함됨)을 설치해야 합니다. ONTAP Select Deploy 관리 유틸리티는 사용하지 않습니다.




[[step-1-prepare-the-ontap-select-cluster-host]]
== 1단계: ONTAP Select 클러스터 호스트 준비

ONTAP Select 클러스터가 배포될 ESXi 호스트를 준비하려면 다음 요구 사항을 따르십시오. 플랫폼 설명은 VMFS-5 또는 VMFS-6 파일 시스템으로 포맷된 로컬 직접 연결 스토리지(DAS)를 사용하는 표준 또는 소형 인스턴스 유형 구성을 기준으로 합니다.

image:prepare_ESXi_host_requirements.png["ESXi 호스트 준비 요구 사항"]

호스트 구성 옵션에 대한 자세한 내용은 link:esxi-host-configuration-and-preparation-checklist.html["ONTAP Select 설치 문서"]을(를) 참조하십시오.



[[step-2-deploy-a-single-node-ontap-select-cluster-using-an-ovf-template]]
== 2단계: OVF 템플릿을 사용하여 단일 노드 ONTAP Select 클러스터 배포

지원되는 64비트 ESXi 호스트 서버에서 다음 단계를 완료하십시오.

.단계
. NetApp 평가 제품 프로그램 페이지로 이동하여 *ONTAP Select*를 선택하면 ONTAP Select OVF 템플릿이 로컬 워크스테이션에 다운로드됩니다.
. 관리자 권한이 있는 계정으로 VMware vSphere 웹 클라이언트에 로그인하십시오.
. 다음 옵션 중 하나를 사용하여 호스트를 선택하십시오.
+
** *파일* > *OVF 템플릿 배포*를 선택합니다.
** *Datacenter*를 선택합니다. 그런 다음 마우스 오른쪽 버튼을 클릭하고 *Deploy OVF Template*을 선택합니다.


. 로컬 워크스테이션에서 ONTAP Select 소스 OVA 파일을 선택한 다음 * Next * 를 선택합니다.
. OVF 템플릿 세부 정보를 검토하고 * 다음 * 을 선택하십시오.
. EULA 세부 정보를 검토하고 * Accept * 를 선택합니다. 그런 다음 *다음*을 선택합니다.
. 새 가상 머신의 이름을 입력하고 *Next*를 선택합니다.
. 데이터 저장소가 두 개 이상 있는 경우 데이터 저장소를 선택하고 *Next*를 선택하십시오.
. *Thick Provision Lazy Zeroed*를 선택한 다음 *Next*를 선택합니다.
. 데이터 및 관리 네트워크를 선택한 다음 *Next*를 선택합니다.
. *속성* 페이지에서 필요한 모든 값을 입력하고 *다음*을 선택합니다.
. 배포 세부 정보를 검토하고 *배포 후 전원 켜기*를 선택하십시오.
. 배포 프로세스를 시작하려면 *Finish*를 선택하십시오.
. ONTAP Select 클러스터가 배포된 후 System Manager 또는 CLI 인터페이스를 사용하여 클러스터를 구성할 수 있습니다. 표준 ONTAP *disk assign* 작업을 사용하여 디스크를 할당해야 합니다.
