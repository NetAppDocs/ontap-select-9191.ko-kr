[role="lead"]
각 ONTAP Select 2노드 클러스터는 mediator 서비스에 의해 모니터링되며, 이 서비스는 노드 간에 공유되는 HA 기능을 관리하는 데 도움을 줍니다.



[[view-the-status-of-the-mediator-service]]
== 중재자 서비스의 상태를 확인합니다

ONTAP Select Deploy 유틸리티에 정의된 각 2노드 클러스터와 관련하여 중재자 서비스의 상태를 확인할 수 있습니다.

.이 작업 정보
각 미디에이터의 구성을 확인할 수 있습니다. 여기에는 현재 상태, 두 개의 ONTAP Select 노드, 그리고 HA 제어 정보가 저장된 iSCSI 타겟이 포함됩니다. 페이지의 객체 위에 마우스를 올리면 자세한 정보가 표시됩니다.

.단계
. 관리자 계정을 사용하여 Deploy 유틸리티 웹 사용자 인터페이스에 로그인하십시오.
. 페이지 상단의 *Administration* 탭을 선택한 다음 *Mediators*를 선택하세요.
. 선택적으로 *필터*를 선택하여 중재자 서비스에서 모니터링하는 2노드 클러스터의 보기 방식을 사용자 지정할 수 있습니다.
