= ONTAP Select 노드 업그레이드
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select 클러스터를 배포한 후 필요에 따라 클러스터의 각 노드에서 ONTAP 이미지를 업그레이드할 수 있습니다.


CAUTION: Deploy 관리 유틸리티를 사용하여 기존 ONTAP Select 노드를 업그레이드할 수 없습니다. Deploy 유틸리티는 새 ONTAP Select 클러스터를 생성하는 데만 사용할 수 있습니다.



[[general-procedure]]
== 일반 절차

전반적으로 기존 ONTAP Select 노드를 업그레이드하려면 다음 단계를 따르십시오.

.단계
. link:https://mysupport.netapp.com/site/downloads/["NetApp Support 사이트 다운로드"^] 페이지에 액세스합니다.
. 아래로 스크롤하여 *ONTAP Select Image*를 선택합니다.
. 설치 이미지의 원하는 릴리스를 선택합니다.
. 최종 사용자 라이센스 계약(EULA)을 검토하고 *Accept & Continue*를 선택하십시오.
. 적절한 *ONTAP Select Image Upgrade* 패키지를 선택하여 다운로드하십시오. 필요에 따라 모든 프롬프트에 응답하십시오.
+
ONTAP Select 노드를 업그레이드하기 전에 추가 정보 및 필요한 절차는 link:reference_release_notes.html["릴리스 노트"]를 검토하십시오.

. ONTAP Select 업그레이드 파일을 사용하여 표준 ONTAP 업그레이드 절차로 ONTAP Select 노드를 업그레이드하십시오. 지원되는 업그레이드 경로에 대한 자세한 내용은 link:https://docs.netapp.com/us-en/ontap/upgrade/concept_upgrade_paths.html["지원되는 ONTAP 업그레이드 경로"^]을(를) 참조하십시오.




[[revert-an-ontap-select-node]]
== ONTAP Select 노드 되돌리기

ONTAP Select 노드는 최초 설치 당시 버전 이전으로 되돌릴 수 없습니다. 예를 들면 다음과 같습니다.

ONTAP Select 9.16.1이 초기 설치됩니다:: 노드를 버전 9.17.1로 업그레이드한 후 필요한 경우 버전 9.16.1로 되돌릴 수 있습니다.
ONTAP Select 9.17.1이 초기 설치됩니다:: 이전에 설치된 버전이 없으므로 되돌릴 수 없습니다.




[[use-the-vmxnet3-network-driver]]
== VMXNET3 네트워크 드라이버를 사용하십시오

VMXNET3은 VMware ESXi에서 새 클러스터를 배포할 때 기본적으로 포함되는 네트워크 드라이버입니다. ONTAP Select 9.4 이하 버전을 실행 중인 기존 ONTAP Select 노드를 업그레이드하는 경우 네트워크 드라이버가 자동으로 업그레이드되지 않습니다. VMXNET3으로 수동으로 업그레이드해야 합니다. 업그레이드 관련 지원이 필요하면 NetApp 지원팀에 문의하십시오.
